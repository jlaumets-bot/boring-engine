### Mechanics that work (for next sessions)
- Lead pages hydrate SLOWLY (banner loads late, Message button drops ~200px) —
  screenshot AFTER settle, then click.
- Composer fields: subject = `input[class*="_subject-field"]`, body =
  `textarea[name="message"]` — set via native value setter + input event.
- Send button: narrow panel at ~(940,596), wide "Open Profile" panel at ~(1054,669);
  Open Profile sends are FREE (no InMail credit).
- Verify each send via /Awaiting reply/ in body text.
- ALWAYS write the link as https://contentshrimp.com — bare domains render as plain text (Day 1 lesson, DOM-verified).
- THE COMPOSER BLOCKER (Day 2 lesson): a `_tooltip-content_` dialog ("Personalize
  your message") eats Message-button clicks. FULL-JS RECIPE that always works:
  (1) remove `[class*="_tooltip-content_"]` nodes, (2) JS-click the Message button,
  (3) poll for `textarea[name="message"]`, (4) fill via native setters + input events,
  (5) wait ~1.2s, (6) JS-click the enabled Send button, (7) poll /Awaiting reply/.
  Two javascript_tool calls per lead, no coordinates needed.
